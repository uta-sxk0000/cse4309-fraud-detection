# Semester project selection

**Project: 4309-04 - Fraud Detection**

**Team:** Sagar Khadka, Bipin Adhikari, Bardan Karki, Samiksha Rijal, Samin Rijal.

Our selected project investigates whether transaction characteristics can identify potentially fraudulent credit card transactions. We use the recommended Credit Card Fraud Detection dataset and compare Logistic Regression, Decision Tree, and Random Forest.

Our question focuses on how class weighting and validation-selected decision thresholds affect fraud detection and false alerts. We evaluate accuracy, precision, recall, F1-score, confusion matrices, ROC-AUC, and average precision on a separate test set. We justify the recommended model based on validation selection, held-out performance, and limitations.

The supplied assignment PDF identifies Fraud Detection as Topic 5. The code 4309-04 is retained from the team's selection.
